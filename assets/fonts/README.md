# Bundled text face

`DejaVuSans.ttf` is the unmodified DejaVu Sans 2.37 regular face from the pinned
Nix environment. It is the default editable-text face on native and browser
targets, so ordinary text uses the same regular weight and metrics everywhere.
The complete redistribution notice is in `DejaVu-LICENSE.txt`.

Old projects with an empty font payload retain the original bundled Ubuntu Light
fallback. Font bytes explicitly stored in a project always remain authoritative.
