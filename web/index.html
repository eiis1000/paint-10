About Paint 10

Paint 10 is a free, open-source MS Paint alternative for the web. It recreates the Windows 10-era Microsoft Paint ribbon, brushes, shapes, and shortcuts in your browser, with no account or installation.

Draw, paste, and edit pictures

Start with a blank canvas, open an image, or paste from your clipboard. Use the pencil, fill bucket, eraser, nine brushes, and 23 shapes. Select, crop, resize, flip, or rotate images; the canvas grows to fit large pasted images and rotated selections.

Classic Paint, with a few extras

Add text you can edit again later, arrange optional layers, work with transparent backgrounds, or zoom in for pixel art. The sun / Auto / moon switch chooses light mode, your system theme, or dark mode and remembers your choice. Touchpad pinch and Ctrl+wheel zoom the picture.

Local files, no uploads

Your pictures are processed on your device, with no image uploads or analytics. Save an image to share, or a .p10 project to keep layers and text editable. Browser saves download a file; download your work before closing or reloading, because pictures are not autosaved.

Keyboard shortcuts
Ctrl+Z / Ctrl+YUndo / redo
Ctrl+C / Ctrl+X / Ctrl+VCopy / cut / paste
Ctrl+WResize, skew, and rotate
Ctrl+ECanvas properties
Ctrl+Shift+XCrop to selection
Ctrl+G / Ctrl+RGrid / rulers
Ctrl+wheelZoom
F10 / F11Ribbon keytips / picture view
EscapeCancel / deselect

Use Command for document and text shortcuts on macOS. Browsers reserve some keys; use the corresponding ribbon command when needed.

Browser and desktop

The web app needs a current desktop browser with JavaScript, WebAssembly, and WebGL. Native builds are available for Linux, Windows, and macOS. See the user guide and desktop setup or the browser guide.
