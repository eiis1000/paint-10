About Paint 10

Paint 10 is a free, open-source MS Paint alternative for the web. It recreates the Windows 10-era Microsoft Paint ribbon, brushes, shapes, and shortcuts in your browser, with no account or installation.

Editable text, images, and equations

Reopen text boxes to change individual words, formatting, or caption outlines. Render LaTeX equations with a live preview and keep their source editable. Inserted images retain their original pixels for reversible crops, color adjustments, and repeated transforms.

Layers and image transforms

Separate artwork into layers with ordering, visibility, locking, and opacity controls. Resize, skew, flip, or rotate images and selections by any angle. Transparent canvases and colors support full alpha.

Drawing and pixel art

Use nine brushes, 23 shapes, gradient fills, and a color editor with CSS input and OKLab/OKLCH. For pixel art, use the 1-pixel pencil, pixel grid, zoom up to 3200%, and nearest-neighbor resizing to keep edges sharp.

Save editable projects

Save a .p10 project to keep layers, text, LaTeX source, and original images, or export a flattened image to share. Files are processed on your device, with no uploads or analytics. Browser saves download a file; pictures are not autosaved, so save before closing or reloading.

Ctrl+ECanvas properties

Ctrl+G / Ctrl+RGrid / rulers
Ctrl+wheelZoom
F10 / F11Ribbon keytips / picture view
EscapeCancel / deselect

Use Command for document and text shortcuts on macOS. Browsers reserve some keys; use the corresponding ribbon command when needed.

Browser and desktop

The web app needs a current desktop browser with JavaScript, WebAssembly, and WebGL. Native builds are available for Linux, Windows, and macOS. See the user guide and desktop setup or the browser guide.
